# R3 验证记录（2026-10-28）

## T07：任务恢复与迟到回写

- 任务记录 worker 身份、执行代次和租约；默认 30 秒租约、最多每 5 秒续租和清扫。未升级的 running 兼容原超时规则，启动取得独占锁后立即终止所有遗留 running。
- 排队任务不因等待时间长而失败；归属不明的调用不自动重放，避免重复费用。
- 进度、成功、失败均校验执行代次及有效租约；job 与结果写入同一事务。失败保留原结论及复核信息，已确认记录不会被覆盖。
- SQLite checkpoint 使用本地 OS 独占锁；线程未退出时继续持锁。它不提供多副本或分布式 worker 支持。
- 每次启动创建新的 asyncio Event，修复 TestClient/多次 lifespan 的跨事件循环复用。
- 新增可重入 Alembic 租约列迁移，覆盖旧表存量数据升级。
- 聚焦：`python -m pytest test/backend/test_job_recovery.py -q`：13 通过（SQLite、Mock、可控时钟）。覆盖快速重启、运行时清扫、20 分钟健康续租、迟到成功/失败、新代次隔离、复核信息保留、独占锁、跨循环重启及迁移。
