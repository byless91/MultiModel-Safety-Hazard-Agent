## T05：向量空间与恢复（2026-10-28 完成）

- 查询失败后将语料和查询同时切换至 `hash:md5-v1:256`，不再按维度是否为 256 猜测空间。
- hash 与 provider embedding 缓存分开，失败查询不覆盖真实缓存；缓存批次数、维度、有限值经过校验才保存。
- 默认 60 秒后允许下一次查询探测恢复，`EMBEDDING_RECOVERY_SECONDS` 可配置。查询与语料候选均校验通过后才切换；失败保留原 hash 索引。
- 索引元信息使用格式版本 2，包含 embedding_space；旧格式或形状不一致的索引使用 embedding 缓存重建，不要求重新向量化未变化语料。

- 检索结果和证据保留 `embedding_space`、`embedding_fallback`；降级和恢复均有日志。本轮不把 hash 分数当成真实语义质量验证结果。
