# R4 验证记录（2026-10-28）

## T10：统一真实 HTTP 并发入口

- 所有 OpenAI-compatible Provider 的 HTTP 请求共享同一进程级 gate；单模型直调、双模型分析、文本细化、整改比对和每批 embedding 均受控。Mock 不请求 HTTP，不占名额。
- 并发默认 4，必须为正数；等待名额默认最多 60 秒，可由 `LLM_QUEUE_TIMEOUT_SECONDS` 配置。排队超时抛出 ModelCapacityError（兼容 ModelUnavailableError），记录 capacity_timeout，无 HTTP、无内部排队重试。
- 每个实际 HTTP 尝试独立获取/释放名额；退避、JSON 解析、台账写入均在 gate 外。异常必经 finally 释放；递归 HTTP 入口明确拒绝，防止嵌套等待。
- 双模型共享线程池只负责任务调度，不在父线程持有 HTTP 名额，不再将线程池大小误称为所有模型并发上限。
- 聚焦：`python -m pytest test/backend/test_llm_concurrency_limit.py -q`，17 passed。使用 httpx.MockTransport 统计真实入口活动数，覆盖 6 请求/4 名额、单/双模型、用途混合、embedding 分批、6 类失败释放、429/503/超时重试、退避让出名额、排队超时及配置校验。

此处“实际 HTTP”指 Provider 的 HTTP 调用边界；测试 transport 为内存假服务，未访问真实模型，未消耗付费额度。T11 与最终回归结果随后补充。
